02 / THE OBJECT

一盏灯，
陪桌面慢慢呼吸。

LAMP—1 不是把更多功能塞进桌面，而是让一盏灯多做一点：把光调到合适的色温，把头转向你正在看的地方，把旧遥控器的手感留在桌面上。

02 / MOVEMENT

安静地转动，
不打断思路。

双轴云台让灯头转向、俯仰，找到一个不需要起身的角度。它移动得很慢，到位后就松开舵机，把嗡嗡声留在机械里，而不是房间里。

03 / CONTROL

物理按键，
先于 App。

不需要先配网、注册、更新固件。长按与短按，把日常动作留在灯座附近完成。

KEY 01遥控

短按发送第一枚红外指令；长按开启或关闭云台静音。

KEY 02灯光

短按开关灯；长按在四组光场景之间循环。

KEY 03学习

长按 3 秒开始学习，灯头轻点一下确认。

好的智能不该先要求一本书的说明书。它应该在你长按三秒之后，就懂你要做什么。

05 / DETAILS

细节，
不急着被看见。

我们把注意力放在每天会碰到、看到、听到的地方。它们不会出现在第一张海报上，但会决定这盏灯是否值得留在桌面上。
