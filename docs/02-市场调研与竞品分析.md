# 02 市场调研与竞品分析

> **数据使用声明**：本文所有市场数字分为两类，务必区分。
> `[估算]` = 由公开常识 + 自下而上推算得出，仅用于判断量级与优先级，**不可直接写入对外 BP**；
> `[待验证]` = 必须通过访谈、样机试用或第三方报告付费购买才能确认的数字。
> 任何对外材料在引用前，都要把 `[估算]` 替换为带来源与年份的真实数据。

## 一、结论摘要（先看这里）

| # | 结论 | 证据强度 | 对策略的影响 |
|---|------|----------|--------------|
| 1 | 学生宿舍"遥控器找不到/被藏/没电/学校不给配"是高频真实痛点 | 中（用户自述，待访谈确认频次） | 红外作为第一优先级入口 |
| 2 | 红外学习硬件成本极低（约 5 元），适合低成本 MVP | 强（BOM 可核算） | 第一轮只做"红外 + 照明"，不做语音 |
| 3 | 台灯是桌面固定物，天然适合做"固定遥控中枢" | 中（逻辑成立，缺使用行为证据） | 形态选择合理，但仍需验证用户是否愿意在灯上管理遥控 |
| 4 | 学习灯赛道已被大厂占据（有道/讯飞/作业帮等），正面进入无胜算 | 强（竞品公开在售） | 学习功能降级为"红外场景的自然延伸" |
| 5 | 情绪陪伴类产品的付费意愿缺乏证据，容易变成"叫好不叫座" | 中（同类产品销量有限） | 机械动作只作为加分项，不作为卖点主线 |
| 6 | 空调"完整状态指令"（模式+温度+风速）匹配难度被普遍低估 | 强（技术常识） | 必须用"学习原始码"而非"协议码库"路线 |

**策略落点**：红外是刚需入口，学习是延长线，情绪是溢价项。顺序不可颠倒。

| 方法 | 样本 | 目的 | 完成时点 |

| 深度访谈 | 12 人（8 学生 / 4 居家办公） | 验证痛点频次与现有替代方案 | 阶段一前 3 周 |

## 三、市场规模测算（自下而上）

### 3.1 总量（TAM）—— 中国高校宿舍桌面照明

```
在校本专科生            ≈ 4,700 万人        [待验证，教育部公报口径]
宿舍桌面灯保有率        ≈ 60%               [估算]
─────────────────────────────────────────
存量桌面灯              ≈ 2,820 万台
年更新/新增率           ≈ 15%               [估算，含新生入学与损坏替换]
─────────────────────────────────────────
年出货量                ≈ 423 万台/年
× 平均可接受单价        ¥179（混合 ASP）
─────────────────────────────────────────
TAM                     ≈ 7.6 亿元/年       [估算]
```

### 3.2 可服务市场（SAM）—— 有红外刚需的细分

红外需求的前提是"宿舍/房间里有需要遥控的家电"，因此按以下条件收窄：

```
一线 + 新一线城市高校学生占比   ≈ 38%      [估算]
其中宿舍配空调或风扇比例        ≈ 70%      [估算，南方更高]
其中"遥控器管理有问题"比例      ≈ 45%      [待验证，访谈核心问题]
─────────────────────────────────────────
SAM 出货量 ≈ 423 万 × 38% × 70% × 45% ≈ 50.6 万台/年
SAM 金额   ≈ 0.9 亿元/年                  [估算]
```

### 3.3 可获得市场（SOM）—— 三年目标

| 年份 | 目标销量 | 占 SAM | 说明 |
|------|----------|--------|------|
| Y1 | 5,000 台 | 1.0% | 验证期，以众筹 + 校园渠道为主 |
| Y2 | 20,000 台 | 4.0% | 进入电商主战场，扩品类到办公人群 |
| Y3 | 50,000 台 | 9.9% | 需新增 SKU 或扩展至非宿舍场景，否则触顶 |

> **诚实提示**：SOM 的上限由 SAM 决定。若三年后仍只有宿舍一个场景，5 万台/年接近天花板。
> 因此 Y2 起必须验证"居家办公桌面"这第二个场景，否则增长故事不成立。

### 3.4 相邻市场（不计入 SOM，但影响估值叙事）

| 相邻市场 | 与本项目的关系 | 风险 |
|----------|----------------|------|
| 万能红外遥控器/红外宝 | 功能高度重叠，价格更低（49–129 元） | 用户可能只买 59 元的红外宝 |
| 智能音箱红外版 | 语音 + 红外一体，生态更强 | 大厂降维打击 |
| 学习灯 | 客单价高，家长付费意愿强 | 赛道拥挤，但可作为"延伸功能"借鉴 |
| 桌搭/潮玩灯具 | 溢价能力最强 | 生命周期短，靠设计而非功能 |

### 4.2 空白位置在哪里

```
                    红外控制能力 →
              无            弱            强
        ┌─────────────┬─────────────┬─────────────┐
   高   │ 有道 / 讯飞  │             │             │
   ↑    │ 装饰台灯     │             │             │
   价   ├─────────────┼─────────────┼─────────────┤
   格   │ 小米 / 欧普  │             │  ★ 本项目    │
        │             │             │  (199-299)  │
        ├─────────────┼─────────────┼─────────────┤
   低   │ 普通台灯     │ 智能音箱红外 │ 红外宝 59-129│
        │             │             │ 万能遥控器   │
        └─────────────┴─────────────┴─────────────┘
```

**空白格**：`照明 + 强红外 + 199–299 元` 这一格目前没有明显占位者。
红外宝有红外但无照明、无桌面存在感；学习灯有照明但无红外。这就是本项目的立足点。

### 4.3 逐个竞品的可攻击面

| 竞品 | 可攻击的弱点 | 但要注意 |
|------|--------------|----------|
| 红外宝 / 万能遥控器 | 需额外 App、配对繁琐、信号不稳、无照明 | 价格只有 1/3，需证明"集成在灯上"值这个差价 |
| 智能音箱红外版 | 需联网、隐私顾虑、老人不会用、离桌面远 | 语音体验成熟，窄域语音不要与之正面比较 |
| 小米/欧普台灯 | 无红外、互动弱 | 品牌、渠道、品控全面碾压，只能差异化 |
| 学习灯 | 贵、家长付费而非用户本人付费、功能冗余 | 不要碰 AI 答疑，那是它们的护城河 |
| 桌搭潮玩灯 | 无实用功能、生命周期短 | 颜值必须不拖后腿，否则"功能机"气质劝退 |

### 4.4 供应链与成本参照

| 参照物 | 公开价格 | 推论 |
|--------|----------|------|
| TSOP38238 红外接收头 | 约 2.2 元（SparkFun 零售 2.25 美元） | 红外 BOM 增量约 5 元，成本不是门槛 |
| 5V/2A 电源适配器 | 8–15 元（CCC 认证） | 降本空间小，不要在电源上省认证 |
| 0.96" OLED | 8–12 元 | 显示是 Plus 版溢价来源之一 |
| SG90 / MG996R 舵机 | 6.5 / 14 元 | 动作机构总增量约 30 元，是 Pro 版溢价基础 |

> 结论：**成本结构不支持"低价走量"**。基础版 BOM 已占售价 57%（500 台批次），
> 只有做到 5000 台批次（占 46.7%）才有毛利空间。详见 `docs/01-商业计划书.md` 的单位经济表。

## 五、用户调研执行包

### 5.1 深访招募条件（12 人）

| 分组 | 人数 | 必须满足 |
|------|------|----------|
| 在校学生 | 8 | 现住宿舍，宿舍有空调/风扇/电视中至少一项 |
| 居家办公 | 4 | 每周在家办公 ≥ 3 天，桌上有台灯或愿买台灯 |

排除：电子/嵌入式专业从业者（会高估功能价值）、本项目成员熟人（会说好话）。

### 5.2 访谈脚本（30 分钟，禁止介绍产品前 20 分钟）

**A. 现状还原（不提问功能，只问事实）**
1. 现在宿舍/房间里的空调、风扇、电视分别怎么控制？请描述上一次用它的完整过程。
2. 过去一个月，有没有出现过"找不到遥控器"的情况？几次？当时怎么解决的？
3. 你手机有红外功能吗？知道有吗？用过吗？（检验"手机替代"假设）
4. 现在桌上的灯是什么？为什么买它？多少钱？用了多久？
5. 你有没有用过定时/倒计时功能（手机、插座、灯）？用完还在用吗？

**B. 痛点强度（量化，避免"挺好的"）**
6. 如果有一个东西能让你不用找遥控器，你愿意为它多付多少钱？（先不给价格锚）
7. 你更愿意：(a) 台灯上多 3 个按键学遥控 (b) 手机 App (c) 语音说一句 (d) 维持现状。为什么？
8. 学一个按键大约需要 3 秒对准按一下，连学 4 个键约 1 分钟，你能接受吗？如果不接受，卡在哪？

**C. 概念反馈（此时才展示概念图/视频）**
9. 这个灯会点头/转向来提示你，你觉得是"有意思"还是"吵/多余"？在什么场合会想关掉？
10. 如果它到点用灯光 + 动作提醒你"该休息了"，你会用吗？多久会用一次？
11. 你觉得这个产品最像什么？你会拿它跟什么比价？（捕捉真实替代品）
12. 299 元、199 元、149 元，你各会怎么想？（记录第一反应词，不要解释）

### 5.3 记录表字段（每人一行）

| 字段 | 取值 |
|------|------|
| 遥控器丢失频次 | 次/月 |
| 现有替代方案 | 手机 / 原遥控 / 手动按机身 / 忍着 |
| 愿付溢价（无锚） | 元 |
| 偏好交互 | 按键 / App / 语音 / 现状 |
| 学习动作接受度 | 1–5 |
| 动作是否干扰 | 1–5 |
| 最先联想到的竞品 | 文本 |
| 价格第一反应 | 文本 |

### 5.4 判定阈值（写死，避免事后自我说服）

| 假设 | 通过阈值 | 不通过则 |
|------|----------|----------|
| H1 遥控器管理是真痛点 | ≥ 8/12 人每月 ≥ 1 次 | 红外降级，重新找入口 |
| H2 愿意在灯上做学习动作 | ≥ 7/12 接受 1 分钟内完成 4 键学习 | 改为一键码库匹配 |
| H3 机械动作是加分 | ≥ 6/12 评分 ≥ 4 且 ≤ 2 人想常关 | 动作降为可选 SKU |
| H4 价格可接受 | 中位可接受价 ≥ 169 元 | 重新设计 BOM 或砍功能 |

### 5.5 定价测试（Van Westendorp 四问，问卷 200 份）

依次提问，**不给任何价格提示**：

1. 多少钱你会觉得**太便宜，怀疑质量**？
2. 多少钱你觉得**划算**？
3. 多少钱开始觉得**贵，但仍会考虑**？
4. 多少钱**绝对不会买**？

分析：取"划算"与"贵但会考虑"的交集为可接受区间；结合 5000 台批次的
BOM（基础 69.62 / 进阶 79.21 / 旗舰 123.49 元）+ 渠道费 5% + 退货 6% + 物流 8 元，
反推最低可接受售价，与实测区间比对，**低于成本线的价格点直接放弃该 SKU**。

## 六、渠道与内容策略（与验证节奏绑定）

| 阶段 | 渠道 | 内容形态 | 目的 |
|------|------|----------|------|
| 验证期 | 校园代理（4 校 20 人）、B站 | "宿舍遥控器消失现场"实拍 + 30 秒学习演示 | 拿到 20 台真实使用数据 |
| 冷启动 | 小红书、什么值得买、众筹 | 拆解视频（红外电路/舵机）、成本公开 | 建立"工程师做的产品"信任 |
| 放量期 | 淘宝/京东/拼多多 | 场景化主图（空调 + 台灯同框） | 转化 |
| 溢价期 | 桌搭社区、礼品渠道 | 外观配色、联名 | 提升 ASP |

**内容主线只有一句**：`不用再找遥控器，喊一声/按一下，灯替你按。`
不要讲"AI"、不要讲"陪伴"，这两个词会拉高预期但无法兑现。

## 七、常见质疑与应答（内部对齐用）

| 质疑 | 应答 |
|------|------|
| 手机/智能音箱不就能控红外？ | 部分手机已取消红外；音箱需联网且不在桌面。我们主打"离线 + 桌面固定 + 零 App" |
| 红外宝 59 元，凭什么卖 199？ | 集成照明 + 免 App + 物理按键 + 定时。若用户不认可，说明该 SKU 不成立，需要转向 Pro |
| 大厂一做就没戏？ | 大厂做的是"生态入口"，我们做的是"单一场景做透"，但窗口期有限（≤18 个月） |
| 机械动作是不是智商税？ | 是加分项不是卖点。Pro 版存在的意义是拉高 ASP 与话题度，不承担走量任务 |
