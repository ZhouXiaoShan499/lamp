## 一、执行摘要

**做什么**：一款放在桌上的智能台灯，核心能力是 **学习并替代你家的空调/电视/风扇遥控器**，
附带 **定时提醒**、**基础照明**，高配版增加 **机械动作与窄域语音**，让交互有反馈、有性格。

**为什么现在做**：
1. 学生宿舍"遥控器被藏、找不到、没电、学校不配"是高频且未被产品化解决的抱怨；
2. 台灯是桌面上唯一"长期通电 + 位置固定 + 用户每天必看"的设备，天然适合做固定遥控中枢；
3. 红外学习模块 BOM 增量仅约 5 元，允许用极低成本先验证需求，再决定是否加语音和动作。

**不做什么**（同样重要）：
- 不做 AI 答疑、不做开放式语音助手（大厂护城河，且推高成本与失败率）；
- 不做"情感陪伴"叙事（无法验证、容易被评价为智商税）；
- 不做自有 App（第一年不做，先用物理按键 + 微信小程序兜底）。

**商业模型**：硬件一次性销售，三档 SKU（149 / 199 / 299 元），以进阶版为主力走量，
旗舰版拉高 ASP 与话题度，基础版仅用于众筹引流与校园批量。

**关键财务（5000 台批次）**：

| 指标 | 数值 |
|------|------|
| 混合 ASP（60/30/10 结构） | 179 元 |
| 混合 BOM | 78 元 |
| 单台贡献毛利 | 49 元（27.4%） |
| 月固定成本 | 1.8 万元 |
| 盈亏平衡销量 | 364 台/月（约 4,400 台/年） |
| 首年 5,000 台结果 | 贡献 24.7 万元 − 固定 21.6 万元 = **+3.1 万元** |

**结论**：这是一个 **微利、需要靠规模与 SKU 结构改善** 的硬件生意。
首年目标不是赚钱，而是用最小成本验证"用户会不会真的用这盏灯管空调"。

## 二、问题与洞察

### 2.1 用户现状（待访谈验证）

| 场景 | 现状做法 | 摩擦点 |
|------|----------|--------|
| 宿舍开空调 | 找遥控器 → 找不到 → 翻床/问室友 → 用手机拍机身按键 | 平均多花 1–3 分钟，情绪成本高 |
| 学校不配遥控器 | 网购万能遥控器 → 配对失败 → 放弃 | 学习流程劝退 |
| 手机红外 | 部分机型已取消红外发射 | 硬件不可用 |
| 睡前关灯关空调 | 起身两次 | 动线长，容易放弃关空调（费电） |
| 学习/工作计时 | 手机番茄钟 → 被消息打断 | 提醒不可靠、易忽略 |

### 2.2 洞察

> 用户要的不是"智能"，是 **"少走两步、少找一次"**。
> 红外之所以是好入口，是因为它解决的是**每天重复 3–10 次**的小摩擦，而不是一次性新鲜感。

### 2.3 待证伪的核心假设

| 编号 | 假设 | 证伪条件 |
|------|------|----------|
| H1 | 遥控器管理是高频痛点 | < 8/12 受访者每月至少 1 次 |
| H2 | 用户愿意在台灯上完成"学习遥控器"动作 | < 7/12 接受 1 分钟内学 4 键 |
| H3 | 定时 + 红外联动会被重复使用 | 2 周内人均使用 < 3 次 |
| H4 | 机械动作是加分而非干扰 | > 2/12 想永久关闭 |
| H5 | 用户愿为组合付 199 元以上 | 众筹转化率 < 1.5% 或中位可接受价 < 169 元 |

## 三、解决方案与产品定义

### 3.1 四层能力（按开发顺序，不可并行）

```
第 1 层  智能照明      双色温、无频闪、记忆亮度        ← 底座，必须可靠
第 2 层  红外学习      学 6 个键，回放，断电不丢        ← 第一优先级，MVP 核心
第 3 层  定时任务      倒计时 / 每日定时 / 与红外联动   ← 第二轮验证
第 4 层  动作与语音    2 轴动作、OLED 表情、20 条命令词  ← 第三轮，看数据再投入
```

**为什么必须串行**：每加一层，BOM +25~50 元、固件复杂度 +1 倍、售后问题 +1 类。
并行开发会把"需求是否成立"和"工程是否能做"两个问题混在一起，无法归因。

### 3.2 SKU 定义

| | 基础版 Basic | 进阶版 Plus（主力） | 旗舰版 Pro |
|---|---|---|---|
| 售价 | 149 元 | **199 元** | 299 元 |
| 照明 | 双色温 5W | 双色温 5W | 双色温 5W |
| 红外 | 学习 6 键 | 学习 6 键 | 学习 8 键 |
| 定时 | - | 倒计时 + 每日定时 | 倒计时 + 每日定时 |
| 显示 | - | 0.96" OLED | 0.96" OLED |
| 动作 | - | - | 点头 + 转向（2 舵机） |
| 语音 | - | - | 20 条离线命令词 |
| BOM(5000) | 69.62 | 79.21 | 123.49 |
| 贡献毛利(5000) | 30.99 | 65.90 | 110.62 |
| 贡献率 | 20.8% | **33.1%** | 37.0% |
| BOM(500) | 84.90 | 96.60 | 150.60 |
| 贡献率(500) | **10.5%** ← 不健康 | 24.4% | 27.9% |

> **重要定价结论（由计算器发现）**：基础版在 500 台试点批次下贡献率仅 10.5%，
> 任何一次退货（计提 6%）或一次售后换新就会亏钱。
> 因此 **首发不推基础版**，用 Plus 199 元作为众筹主档，基础版延后到 5000 台批次再上。

### 3.3 用户体验主流程（必须 60 秒内跑完）

```
① 插电 → 灯亮（默认 4000K / 60% 亮度，不刺眼）
② 长按「学习」3 秒 → 屏幕显示 "IR LEARN 1/6" → 灯头轻点一下（确认进入学习）
③ 把空调遥控器对准灯头 5cm 内 → 按"开/关" → 蜂鸣 + 屏幕 "OK 1"
④ 重复学 温度+ / 温度- / 模式 / 风速（共 6 键）
⑤ 退出学习 → 按「空调」键 → 灯发射刚才学的码 → 空调响应
```

失败兜底：学习超时 15 秒自动退出并保留已学按键；同一槽位可重学覆盖；
连续 3 次学习失败 → OLED 提示"距离过远/请换电池"（这是真实高频原因）。

## 四、商业模式

### 4.1 收入结构

| 来源 | 首年占比 | 说明 |
|------|----------|------|
| 硬件销售 | 95% | 三档 SKU |
| 配件 | 3% | 可插拔红外延长线、桌面支架 |
| 服务 | 2% | 定制外观（企业礼品） |

**明确不做**：订阅制。用户买的是"替代遥控器"，不是内容服务，订阅会直接杀死转化。

### 4.2 单位经济（5000 台批次，由计算器输出）

| 项目 | 基础 | 进阶 | 旗舰 |
|------|------|------|------|
| 零售价 | 149.00 | 199.00 | 299.00 |
| − BOM | 69.62 | 79.21 | 123.49 |
| − 模具摊销（4.5 万 / 5000） | 9.00 | 9.00 | 9.00 |
| − 物流 | 8.00 | 8.00 | 8.00 |
| − 渠道费 5% | 7.45 | 9.95 | 14.95 |
| − 退货计提 6% | 8.94 | 11.94 | 17.94 |
| − 营销 CAC | 15.00 | 15.00 | 15.00 |
| **= 单台贡献** | **30.99** | **65.90** | **110.62** |
| 贡献率 | 20.8% | 33.1% | 37.0% |
| 盈亏平衡（月固定 1.8 万） | 581 台/月 | 273 台/月 | 163 台/月 |

### 4.3 成本改善路径（按杠杆大小排序）

| 杠杆 | 影响 | 难度 | 备注 |
|------|------|------|------|
| 提高批次量 500→5000 | BOM 降 18% | 中 | 需要销量支撑，有库存风险 |
| 去掉 4 层板改 2 层 | −2 元 | 低 | 需重新评估 EMC |
| 电源改为内置（省外壳与线材） | −3 元 | 中 | 增加 3C 认证复杂度 |
| 结构件改型材 + 3D 打印小批 | −4 元 | 低 | 只适合 ≤1000 台 |
| 舵机改用国产替代 | −4 元 | 中 | 需寿命测试（≥2 万次） |

**不要动的地方**：电源认证、红外接收头、LED 驱动。这三项省钱的代价是批量退货。

## 五、财务预测

### 5.1 三年损益（保守口径，不含融资）

假设：Y1 混合 ASP 179 元、BOM 系数 0.82；Y2 销量 2 万台、BOM 系数 0.78、CAC 降至 12 元；
Y3 销量 5 万台、BOM 系数 0.74、CAC 降至 10 元。退货计提 6%、渠道费 5% 保持不变。

| 项目（万元） | Y1 | Y2 | Y3 |
|--------------|-----|-----|-----|
| 销量（台） | 5,000 | 20,000 | 50,000 |
| 收入 | 89.5 | 358.0 | 895.0 |
| BOM | 39.0 | 148.3 | 352.0 |
| 模具摊销 | 4.5 | 4.5 | 4.5 |
| 物流 | 4.0 | 16.0 | 40.0 |
| 渠道费 | 4.5 | 17.9 | 44.8 |
| 退货计提 | 5.4 | 21.5 | 53.7 |
| 营销 | 7.5 | 24.0 | 50.0 |
| 固定成本（含人力） | 21.6 | 36.0 | 60.0 |
| **税前利润** | **+3.0** | **+90.3** | **+330.0** |
| 利润率 | 3.4% | 25.2% | 36.9% |

> 口径说明：Y2/Y3 的固定成本按 3 人 / 5 人小团队估算，未含厂房与设备。
> Y3 的 36.9% 利润率对硬件业务偏高，实际会被人力扩张、认证、模具迭代吃掉，**视为上限**。

### 5.2 敏感性分析（Y1 利润，万元）

| 销量 \ 贡献毛利 | 40 元/台 | 49 元/台（基准） | 60 元/台 |
|------------------|----------|------------------|----------|
| 3,000 台 | −9.6 | −6.9 | −3.6 |
| 5,000 台 | −1.6 | **+3.0** | +8.4 |
| 8,000 台 | +10.4 | +17.6 | +26.4 |

**读法**：在 5,000 台销量下，单台贡献低于约 43 元就会亏损。
而基础版单台贡献仅 31 元（5000 台批次）—— 这再次说明 **不能靠基础版走量**。

### 5.3 现金流要点

| 事项 | 金额 | 时点 |
|------|------|------|
| 模具（注塑 2 套） | −4.5 万 | M3 |
| 首批 300 台物料 | −3.0 万 | M3 |
| 3C 认证 + EMC 预测试 | −3.5 万 | M4 |
| 众筹回款（30 天结算） | +15~30 万 | M5 |
| 电商备货（2 个月周转） | −8 万 | M6 |

**风险点**：众筹回款晚于备货付款时，会出现 2–3 周的资金缺口。
应对：首批只备 300 台，众筹超募后再下第二批；不接受账期超过 45 天的渠道。

## 六、进入市场策略（GTM）

### 6.1 四步走

| 步骤 | 时间 | 动作 | 通过标准 |
|------|------|------|----------|
| 1. 种子验证 | M1–M2 | 20 台样机进 4 间宿舍，2 周日志 | 人均红外使用 ≥ 3 次/周 |
| 2. 众筹冷启动 | M3–M4 | 京东/淘宝众筹，主推 Plus 199 | 转化率 ≥ 1.5%，超募 ≥ 100% |
| 3. 电商放量 | M5–M8 | 淘宝/京东自营店，B站测评 | 月销 ≥ 300 台，退货率 ≤ 6% |
| 4. 渠道扩展 | M9–M12 | 校园代理、企业礼品、拼多多基础版 | 单月 ≥ 500 台 |

### 6.2 首销话术（三个版本，A/B 测试）

| 版本 | 主标题 | 假设 | 观测指标 |
|------|--------|------|----------|
| A 痛点型 | "宿舍空调遥控器又找不到了？" | 痛点驱动 | 点击率、加购率 |
| B 功能型 | "一盏会学遥控器的台灯" | 功能驱动 | 详情页停留、转化率 |
| C 趣味型 | "会点头的台灯，替你把空调开了" | 情绪驱动 | 分享率、评论量 |

**预期**：A 转化最高但人群窄，C 传播最好但退款率高。用数据决定主图，不靠审美投票。

### 6.3 不投放的渠道（首年）

- 抖音信息流（CPM 高、退货率高，不适合低客单 3C）
- 百度竞价（搜索量小，长尾贵）
- 线下数码店（账期与压货风险）

## 七、运营与供应链

### 7.1 生产方案

| 阶段 | 数量 | 方式 | 单位成本 | 备注 |
|------|------|------|----------|------|
| 原型 | 5 台 | 手工焊接 + 3D 打印 | ~450 元/台 | 验证功能 |
| 小批 | 300 台 | 深圳代工（PCBA + 组装） | 按 500 台 BOM | 需驻厂 3 天验货 |
| 量产 | 5,000 台 | 同一代工厂扩产 | 按 5000 台 BOM | 需 SMT 首件确认 + 抽检 |

### 7.2 质量控制（三条红线）

1. **红外学习成功率**：抽检 30 台 × 5 品牌遥控器，首次学习成功率 ≥ 90%，否则不出货。
2. **电源与温升**：满载 2 小时，外壳可触及部位 ≤ 45K 温升（GB 7000.1 要求）。
3. **舵机寿命**：Pro 版抽检 3 台，连续动作 2 万次无卡死、无齿轮异响。

### 7.3 售后策略

| 问题 | 处理 | 成本上限 |
|------|------|----------|
| 学不会某品牌遥控器 | 远程指导 + 寄送"码库补丁"（OTA） | 0（软件） |
| 舵机异响 | 寄修，免运费 | 25 元/次 |
| 灯珠死灯 | 整机换新 | 78 元/次 |
| 7 天无理由 | 正常退 | 计提 6% 已覆盖 |

**关键**：把"学不会"变成 OTA 可解的问题，而不是退货。
固件需支持从 LittleFS 加载码库补丁文件，这是设计的隐含要求（见 `03-技术方案.md`）。

### 8.1 最小可行团队（验证期）

| 角色 | 人数 | 职责 | 缺口 |
|------|------|------|------|

**可以外包**：ID 设计、模具、3C 认证代理、代工生产、客服。
**不能外包**：红外协议适配与固件核心逻辑。

## 十、里程碑与 KPI

| 阶段 | 时间 | 交付物 | KPI（硬门槛） |
|------|------|--------|----------------|
| Gate 0 需求验证 | M0–M1 | 12 人访谈 + 假设判定 | H1 ≥ 8/12，H2 ≥ 7/12 |

| Gate 4 扩展决策 | M9–M12 | Pro 版 or 学习功能 | 红外周使用 ≥ 3 次/人，NPS ≥ 30 |

**任一 Gate 不通过，就停在该阶段做修正，不允许"先做出来再说"。**

## 十二、明确写在纸上的假设（便于日后复盘）

1. 目标用户以在校学生为主，宿舍是主要场景。
2. 用户每天会与空调/风扇遥控交互 ≥ 2 次。
3. 用户愿意为"不用找遥控器"支付 50–100 元溢价（相对普通台灯）。
4. 红外学习动作可以在 1 分钟内完成，且用户不觉得麻烦。
5. 语音不是必需项，按键 + 语音的组合优于纯语音。
6. 机械动作提升好感但不改变购买决策。
7. 供应链可以在 500 台量级找到愿意接单的代工厂。
8. 3C 认证费用在 3.5 万元以内、周期 6 周以内。

> 以上任一条被证伪，第五节财务预测与第三节 SKU 结构都需重算。
> 修改假设时，同步更新 `tools/mvp_calc.py` 中的常量，**不要只改文档里的数字**。
